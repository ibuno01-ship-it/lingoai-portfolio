# LingoAI — AI-Powered Japanese Localization SaaS

A portfolio concept by **Ibuki Hasegawa**.

LingoAI is a responsive front-end concept for an AI-powered Japanese localization SaaS. It demonstrates a modern SaaS landing page, a polished product UI, and an interactive English-to-Japanese localization demo.

## Highlights
- Responsive SaaS landing page
- Interactive localization demo
- Natural / Professional / Friendly tone selector
- Japanese localization use case
- Feature, workflow, comparison, pricing, and CTA sections
- Mobile-friendly design

## Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript

## Demo behavior
The localization UI is a front-end prototype with simulated responses. It does **not** call a production AI API.

## Purpose
This project was created as a web-development portfolio piece to demonstrate front-end implementation, responsive design, UI composition, and Japanese/English localization knowledge.
